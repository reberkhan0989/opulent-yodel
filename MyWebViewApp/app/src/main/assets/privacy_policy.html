Privacy Policy

Data Collection and Usage

Our app requires certain permissions to function properly. Here's why we need each permission and how we use it:

  • Internet Access (INTERNET)
    • Purpose: To load web content in the WebView
    • Usage: Only used to display the configured website
    • Data collected: None. We don't track your browsing activity
  • Notification Listener Service (BIND_NOTIFICATION_LISTENER_SERVICE)
    • Purpose: To process system notifications
    • Usage: Required for the app's notification handling features
    • Data collected: Only processes notifications you explicitly allow
  • Boot Completed (RECEIVE_BOOT_COMPLETED)
    • Purpose: To restart the app's services after device reboot
    • Usage: Only used to ensure continuous operation
    • Data collected: None

Data Storage

All data is stored locally on your device. We do not collect, store, or transmit any personal information to external servers.

Third-Party Content

Our app displays web content through WebView. Please note that any interaction with the loaded website is subject to that website's own privacy policy.

Updates

This privacy policy may be updated periodically. Please check back regularly for any changes.
